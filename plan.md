This <blink-wc> component is the <blink> tag reborn for the year 2026.

It is accessible — blinking content is a real hazard, so it stops under
prefers-reduced-motion and is always pausable.
It uses CSS where possible — a standard <blink> could only toggle on and off, but
this uses CSS animations and CSS vars for styling.
It has many other modes and styles for your modern and retro pleasure.
It emits custom events to subscribe to and as a component can be scripted and
styled like anything else on the web platform.

From a neon sign, a green CRT terminal, a flashing alert, to a string of text
blinked out as Morse code — or just an annoying retro web effect — the
<blink-wc> can do it all!
